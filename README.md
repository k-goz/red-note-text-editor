# Red Note Text Editor

> 小红书长文排版工具 - 一键排版，让长文也能优雅呈现

一个帮助创作者将长文本自动排版成小红书图片格式的前端工具。

## 在线使用

**[点击这里立即体验](https://k-goz.github.io/red-note-text-editor/)**

无需下载，直接在浏览器中使用！

## 功能特点

### 核心排版
- **智能分页**：段落整体分页，支持段落跨页续排，内容不会溢出页码/水印
- **实时预览**：左侧任何变动（文本、配置）自动实时更新右侧预览
- **自动排版**：6种排版风格一键优化，支持智能识别文本类型
- **Markdown支持**：标题、加粗、斜体、下划线、删除线、彩色文字、引用块、列表、分割线、代码块、表格

### 视觉定制
- **11种背景颜色**：纯色、渐变（粉/蓝/紫）
- **6种纹理效果**：纸张、点阵、横线、网格、笔记本、便笺
- **5种风格预设**：经典备忘录、现代笔记、复古纸张、简约清新、温暖日记
- **7种图片比例**：含小红书推荐 3:4 和自定义尺寸
- **9种内置字体** + 自定义字体上传

### 效率工具
- **草稿自动保存**：编辑内容每30秒自动保存，刷新不丢失
- **模板管理**：保存当前配置为模板，一键复用排版风格
- **撤销/重做**：支持50步历史，Ctrl+Z / Ctrl+Y
- **快捷键**：Ctrl+B 加粗、Ctrl+I 斜体、Ctrl+U 下划线、Ctrl+S 保存
- **Emoji选择器**：6大分类常用Emoji快捷插入
- **深色模式**：GitHub风格深色主题，护眼编辑

### 导出
- **批量导出**：支持单页或全部页面一键下载
- **高清图片**：4倍分辨率导出，预览与下载100%一致
- **水印/页眉/页码**：自定义水印文字、页眉文字和对齐方式

## 使用方法

1. **访问工具**：[点击这里](https://k-goz.github.io/red-note-text-editor/)
2. **输入文本**：在左侧文本框粘贴或输入你的长文，支持Markdown格式
3. **调整设置**：字体、行高、图片比例、背景、纹理等
4. **实时预览**：左侧任何变动自动更新右侧预览（可关闭）
5. **下载图片**：预览满意后下载单页或全部页面

## 本地开发

```bash
# 克隆项目
git clone https://github.com/k-goz/red-note-text-editor.git

# 进入项目目录
cd red-note-text-editor

# 用浏览器打开
open index.html  # macOS
```

## 技术栈

- 纯原生 HTML/CSS/JS，零框架依赖
- html2canvas@1.4.1（唯一外部依赖，用于图片导出）
- CSS Variables 实现深色模式
- localStorage 实现草稿保存和模板管理
